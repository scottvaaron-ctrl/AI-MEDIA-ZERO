# TikTok posting notes (owner completes in the TikTok app)

1. Open TikTok, tap +, upload `video.mp4`.
2. Paste `caption.txt` (edit freely; you must be the final editor).
3. Choose the cover (suggested: `cover.png` or the frame at 0.5s).
4. Turn ON the 'AI-generated content' label (narration and script are AI-assisted).
5. Select the privacy level yourself. Nothing here sets it for you.
6. Sources are in `sources.json`; consider pinning a comment with the main source.
7. After posting, record views/likes/shares/comments with `aimz metric add` (TikTok exposes no watch-time API to normal apps).

Recommended posting time (local): 2026-09-08T17:00
